HOW TO USE (No coding needed)
1) Go to https://app.netlify.com/drop and drag this folder (or the zip). Netlify gives you a URL like https://something.netlify.app
2) In Supabase > Authentication > URL Configuration:
   - Site URL: https://YOUR-SITE.netlify.app
   - Redirect URLs: https://YOUR-SITE.netlify.app
3) Open your site. Paste your SUPABASE URL and Publishable Web Key, click Save, then "Continue with Google".
4) If it returns and shows a JSON session, Google login works.
